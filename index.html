How to use the Wreath Order app

Tap a topic to open it. Everything you enter stays on this device — nothing is sent anywhere unless you send a backup or a tally sheet yourself.

1. Getting started (do this once)
  1. Install it on your phone so it works without internet:
    • iPhone: open the link in Safari → tap Share (square with arrow) → Add to Home Screen.
    • Android: open the link in Chrome → tap ⋮ → Install app (or Add to Home screen).
    Then always open it from the new Wreaths icon.
  2. Go to Setup and type Your cadet's name. Every order you take is credited to that cadet. (Leave it blank only if several cadets share one device.)
  3. Check the Year, Fundraiser dates, and Prices on the Setup tab.
  4. Optional: Load last year's tally sheet (Setup → Returning customers) so repeat customers pop up as you type.
Each new download starts completely empty — no one else's orders come with it.
2. Taking an order
  1. Tap New Order.
  2. Type the customer's name. If they're a returning customer, tap their name in the list that pops up — phone (and address) fill in for you, and you'll see what they bought last year with a Same as last year button.
  3. Enter a phone or email.
  4. Address: fill it in only if you'll deliver door-to-door. Leave it blank for church pickup.
  5. Use + and − to set quantities. The total updates at the bottom.
  6. Pick how they paid (see Payments below), add any Notes, then tap Save order.
If the same name already ordered this year, the app asks before saving a second order — so you don't double-enter someone.
3. Payments
  • 💵 Cash, 🧾 Check (type the check number), 💳 Credit Card, or 📱 Venmo / PayPal (optionally note which app or username).
  • ⏳ Not paid yet — use this if they'll pay later. The order is flagged in red everywhere, shows on the Totals tab as money still owed, and the Paid column on the tally sheet is left blank with "NOT PAID" in the notes.
  • When an unpaid customer pays: go to Orders → Edit → choose how they paid → Update order. On distribution day you can also tap 💵 Mark paid on their card.
4. Orders & Totals tabs
  • Orders lists everything you've taken. Search by name, phone, or address. Use Edit to fix a mistake or Delete to remove an order.
  • Totals shows how many of each item to order from the supplier, money collected by payment type, money still owed, and sales by cadet.
5. Backups — sending your orders to the troop
  1. Tap Save backup (top of the screen).
  2. On a phone, the share menu opens — pick Mail (or Messages) and send it to the troop's order coordinator. On a computer, the file downloads.
  3. The coordinator opens their copy of the app → Setup → Load a backup file → choose Merge to add your orders to theirs.
Save a backup after every session of taking orders. If your phone is lost or its browser data is cleared, the backup is the only copy.
6. Making the Excel tally sheet
  1. Go to Setup → Export to the Tally Sheet.
  2. Choose which orders (all, or one cadet), then tap Download Tally Sheet (.xlsx).
  3. Open it in Excel — totals calculate automatically. Each sheet holds 52 customers; bigger lists come out as page 1, page 2, etc.

Simple order list (.csv) gives a plain spreadsheet of every order if you'd rather sort and filter yourself.

7. Distribution day (handing out wreaths)
  1. Open the Distribution tab (Deliver on phones).
  2. Tap Load tally sheets / backups and pick the files each family sent in (you can pick several at once). Tap Add this device's orders to include orders taken on this device.
  3. Search for each customer as they arrive. Check off each item as you hand it over, or tap ✓ All handed out.
  4. Customers missing something show as Partly. Finished customers drop off the "Still to hand out" list (switch the filter to Everyone or Done to see them; Undo reverses a mistake).
  5. Red Not paid tags show who still owes money — collect it, then tap 💵 Mark paid.
  6. Filters: Door-to-door only for delivery drivers, Not paid yet for collections. Print list gives a paper backup.
  7. The bottom section shows items still waiting, and lets you download tally sheets with Delivered marked or a delivery report.
If a family sends an updated file, just load it again — their list is replaced but your check marks are kept.
8. Starting fresh
  • Setup → Erase orders only: removes this device's orders but keeps settings and returning customers.
  • Setup → Reset everything: makes the app like a brand-new copy (orders, roster, returning customers, cadet name, price changes). Use this when handing a device to another cadet or starting a new year.
  • Save a backup first if you might need anything.
9. Troubleshooting
  • My orders disappeared. Orders live in this browser on this device. They're lost if you clear browsing data, use a private/incognito window, or open the app in a different browser. Load your latest backup (Setup → Load a backup file).
  • iPhone: always use the home-screen icon. A page left open only in a Safari tab can have its data cleared by iOS if it goes unused for a while.
  • Two devices, different orders. Each device keeps its own list. Combine them with Save backup → Load a backup file → Merge.
  • The app looks out of date. Open it once with internet, close it, and open it again — updates install in the background.
  • Can't find a downloaded file on iPhone. Look in the Files app → Downloads.

Export to the Tally Sheet

Creates a filled-in copy of the official tally sheet (.xlsx) — names, phones, quantities, paid, picked-up, and payment notes. Excel recalculates the totals when you open it. The sheet holds 52 customers, so bigger lists are split into page 1, page 2, etc.

Returning customers

Load last year's tally sheet(s) so names and phone numbers pop up as you type. You can load several files (e.g. one per cadet). A simple CSV with Name and Phone columns works too.

Backup & other computers

Orders are saved automatically on this device. Tap Save backup (top) now and then — on a phone it opens the share menu so you can email or text the file. To combine devices, load the other device's backup here and choose Merge.
